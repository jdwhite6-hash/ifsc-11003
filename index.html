Thoughts on Progressive Enhancement

I believe this is important for the development of the modern web because it goes away from the previous model of graceful degradation, where you made a complex site and then tried to simplify it to work on older browsers. Progressive enhancement flips that mindset. Instead of building something heavy and stripping it down, you build a strong, accessible foundation first and layer on improvements only when the user’s device and browser support them.

This approach leads to sites that are faster, more resilient, and more inclusive. A user with a slow network, an older device, or JavaScript disabled still gets a functional experience. Meanwhile, users with modern browsers get richer interactions and smoother UI/UX. It encourages developers to think about accessibility, performance, and content quality from the very beginning rather than as an afterthought.

Final Reflection

When I showed a user the first draft of my final project, I was told the site had a lot to improve upon. I was told to improve the color because it was lacking color, optimize the pictures because the site tended to load slowly, add media queries to enhance the experience for mobile users, make it seem more like space, and make sure to validate the HTML before duplicating it across pages.

I think I did a really good job giving the website life with adding CSS, JavaScript, and a contact form to reach out. Though, I feel I could've done better with the color scheme and making it more space themed. I did a great job listening to the feedback and changing things that could help the user experience. I think if I could start over again, I think I would make this project something I could reuse even after this class like a portfolio or a resume, but I feel that I did the best that I could do with this concept.
